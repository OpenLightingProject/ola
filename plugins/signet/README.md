Sig-Net Plugin
===============================

This plugin allows OLA to send and receive
[Sig-Net](https://sig-net.net/) messages.


## Config file: `ola-signet.conf`

`input_ports = <int>`  
The number of input ports to create.

`output_ports = <int>`  
The number of output ports to create.

`udp_listen_port = <int>`
The UDP Port to listen on for Sig-Net messages.
